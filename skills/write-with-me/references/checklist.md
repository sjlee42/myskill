# 점검표

## A. 잘 쓴 글인가

1. **문항에 답했나**: 문항 원문을 다시 읽고, 묻는 것 각각에 대응하는 문장을 짚을 수 있는가
2. **요지가 하나인가**: 글 전체를 한 문장으로 말할 수 있는가
3. **구체적인가**: 장면, 숫자, 고유명사, 실제 한 말이 있는가. 문단마다 하나 이상
4. **이 사람만 쓸 수 있는 글인가**: 이름만 바꿔서 다른 지원자가 내도 말이 되는 문장이 있으면 지우거나 구체화한다
5. **사용자 말이 남아 있나**: `material.md`의 ★ 표현이 살아 있는가
6. **지어낸 것이 없나**: 사실·경험·수치·감정·판단·각오가 모두 `material.md`에 근거가 있는가(`[초안에서]` 표시 포함). 연결어, 순서, 문단 구성은 모델이 만들어도 된다. 근거 없는 내용은 지우거나 사용자에게 묻는다
7. **첫 문장과 끝 문장**: 첫 문장이 장면이나 핵심인가(300자 이하 문항은 핵심을 먼저). "저는 어릴 때부터", "안녕하세요"로 시작하지 않는가. 끝이 상투적인 다짐이 아니라 구체적인 기대나 계획인가
8. **분량**: 제한 글자 수의 90~100%. `scripts/count.py`로 공고 기준(공백 포함/제외)에 맞춰 센다

## B. AI 티 (한국어)

### 번역투
- "~을 통해" → "~로", "~해서"
- "~에 있어서", "~에 있어" → "~에서", "~할 때"
- "~에 의해 ~되다" → 능동으로
- "~하는 것이 중요하다", "~할 필요가 있다" → 직접 말한다
- "~을 가지고 있다" → "~이 있다"
- "다양한", "효과적인", "효율적인", "혁신적인" 같은 형용사 남발
- 과도한 명사화: "성장에 대한 갈망을 가지게 되었습니다" → "더 잘하고 싶어졌습니다"

### AI 상투어
- 마무리: "결론적으로", "이처럼", "요컨대", "시사하는 바가 크다", "~의 중요성을 깨달았습니다"
- 과장된 의의: "단순한 ~가 아닌", "~를 넘어", "새로운 지평", "한 단계 도약"
- 뜬금없는 다짐: "최선을 다하겠습니다", "성장하는 인재가 되겠습니다"
- 감탄 시작: "~은 정말 흥미로운 주제입니다"

### 구조
- 기계적인 셋 나열("첫째, 둘째, 셋째", 형용사 세 개 연달아)
- 모든 문단이 같은 길이, 같은 리듬
- 문장마다 접속사로 시작("또한", "더불어", "나아가")
- 줄표(—), 곡선 따옴표, 불릿과 굵은 글씨를 산문에 남발
- 질문하고 바로 답하기("왜일까요? 바로 ~때문입니다")

## C. 고칠 때 원칙

- 탐지된 부분만 고친다. 멀쩡한 문장을 건드리지 않는다.
- 사용자의 실제 말투가 번역투라면(예: 원래 "~를 통해"를 쓰는 사람) 억지로 바꾸지 않는다. 사용자에게 물어본다.
- 고친 내용은 "무엇을 → 왜" 형식으로 짧게 알린다.
